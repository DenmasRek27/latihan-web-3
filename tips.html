Mengapa HTML Penting

HTML adalah bahasa dasar yang digunakan untuk membuat struktur halaman web. Tanpa HTML, browser tidak bisa menampilkan teks, gambar, maupun link dengan rapi dan terstruktur.

Memahami HTML sangat penting sebelum belajar CSS dan JavaScript. Dengan HTML yang baik, pembuatan website akan menjadi lebih mudah dan terstruktur sejak awal.

Tips Pertama

  1. Pahami struktur dasar HTML seperti doctype, head, dan body.
  2. Gunakan tag semantic agar struktur web mudah dibaca.
  3. Selalu gunakan atribut alt pada setiap tag gambar.
  4. Coba latihan membuat kodingan sederhana secara konsisten.
  5. Cek hasil kodingan di W3C Validator untuk memastikan tidak ada error.

Kesalahan Umum

  • Lupa Menutup Tag

    Lupa menutup tag seperti tag p atau div bisa membuat tampilan web jadi berantakan.

  • Pakai Div Sembarangan

    Menggunakan div untuk semua bagian tanpa menggunakan tag semantic seperti header atau section.

  • Lupa Atribut Alt Gambar

    Memasang gambar tanpa atribut alt sehingga pembaca layar tidak bisa membaca deskripsi gambar.

  • Urutan Heading Berantakan

    Menggunakan h1, h3, h2 secara tidak berurutan sehingga struktur dokumen kurang rapi.
